kavier-co2 — emissions

Walk a workload's power profile through a carbon-intensity trace (gCO2/kWh over time) to estimate total CO2, time window by time window.

Carbon intensity varies by hour and grid, so emissions depend on when and where a job runs. kavier-co2 takes a power profile and a carbon-intensity trace, slices the run into the trace's time windows, and sums energy × intensity per window. The power profile can come from two sources:

  • --from-training — build the profile directly from a kavier-train config (the analytical model's predicted power × runtime).
  • --powersource — read an OpenDC powerSource.parquet (e.g. from an inference run).

Exactly one of the two modes is required.

Flags & options

Flag / OptionTypeDefaultDescription
--carbon_tracepathrequiredCarbon-intensity Parquet (gCO2/kWh).
--carbon_step_minutesint(inferred)Override the inferred trace step.
--from-trainingflag—Mode: build the profile from a training sim (mutually exclusive with --powersource).
--powersourcepath—Mode: read an OpenDC powerSource.parquet.
--output_csvpath(unset)Write the per-window breakdown to CSV.

With --from-training, these are also required

FlagTypeDescription
--model_namestrLLM key (e.g. mistral-7b-v0.1).
--methodfull | lora | gptq-loraFine-tuning method.
--gpu_modelstrGPU key (e.g. NVIDIA-A100-SXM4-80GB).
--tokens_per_sampleintSequence length.
--batch_sizeintSamples per GPU per step.
--number_gpusintGPUs per node.
--number_nodesintNumber of nodes.
--total_tokensintTotal tokens to train over (sets the runtime).
--start_timestrRun start, naive timestamp, e.g. '2025-06-01 00:00'.

Example: from a training config

kavier-co2 --from-training \
  --carbon_trace      ct1-2025-ie-carbon-intensity.parquet \
  --model_name        mistral-7b-v0.1 \
  --method            lora \
  --gpu_model         NVIDIA-A100-SXM4-80GB \
  --tokens_per_sample 1024 \
  --batch_size        4 \
  --number_gpus       8 \
  --number_nodes      1 \
  --total_tokens      100000000 \
  --start_time        '2025-06-01 00:00' \
  --output_csv        emissions_breakdown.csv

Example: from an OpenDC power profile

kavier-co2 \
  --carbon_trace carbon_trace.parquet \
  --powersource results/run-01/powerSource.parquet

Output

============================================================
Kavier CO2 Emissions
============================================================
Total energy:        312.5000 kWh
Total CO2:           87,500.00 g  (87.5000 kg)
Avg intensity used:  280.00 gCO2/kWh (energy-weighted)
Windows touched:     48
============================================================

With --output_csv, each row is one time window: window_start, carbon_intensity, energy_kwh, co2_g. The energy-weighted average intensity reflects when the job actually drew power, not a flat grid average.
