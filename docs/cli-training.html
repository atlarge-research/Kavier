kavier-train
Command line · 04

Kavier Training

Simulate a single training configuration, or simulate every row of a CSV.

Simulate every row of a CSV

Simulate every row of a CSV (e.g. data/input/input_example.csv).

kavier-train --input_csv src/data/input/input_example.csv

Each row supplies a full config (model_name, method, gpu_model, tokens_per_sample, batch_size, number_gpus, number_nodes); the simulator prints one line per configuration with the resulting tokens/sec and runtime, then a count of how many configurations were simulated.

Flags & options

Flag / OptionTypeDefaultDescription
--input_csvpath(unset)Simulate every row of this CSV instead of a single config.
--model_namestrrequired*Key of the model to simulate.
--methodfull | lora | gptq-lorarequired*Training / fine-tuning method.
--gpu_modelstrrequired*GPU model key, e.g. NVIDIA-A100-SXM4-80GB.
--tokens_per_sampleintrequired*Sequence length — tokens per sample.
--batch_sizeintrequired*Samples per GPU per step.
--number_gpusintrequired*GPUs per node.
--number_nodesintrequired*Number of nodes (total GPUs = number_gpus × number_nodes).
--total_tokensint(unset)Total tokens to train over, used to estimate full runtime.
--opendc_output_dirpath(unset)If set, export an OpenDC-compatible workload to this directory.
--opendc_task_idint0Task id used in the OpenDC export.
--opendc_submission_time_msint0Submission time (ms) used in the OpenDC export.

* Required for single-config runs; alternatively pass --input_csv to simulate every row of a CSV.

Single-config example

kavier-train --model_name mistral-7b-v0.1 --method lora \
  --gpu_model NVIDIA-A100-SXM4-80GB --tokens_per_sample 1024 \
  --batch_size 4 --number_gpus 8 --number_nodes 1

On bad or missing arguments

On bad/missing arguments, the CLI shows a ready-to-run example command:

friendly error

You may have mistaken the input — try this example instead:

kavier-train --model_name mistral-7b-v0.1 --method lora \
  --gpu_model NVIDIA-A100-SXM4-80GB --tokens_per_sample 1024 \
  --batch_size 4 --number_gpus 8 --number_nodes 1
