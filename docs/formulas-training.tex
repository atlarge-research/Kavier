% Kavier training-simulator formulas — verified against

% (branch simplify-kavier-periphery, held-out calibration v3).
%
% Conventions: \textbf{bold} = computed quantity, plain = received input,
% \underline{underline} = calibration term. Calibration terms that depend on
% the configuration are written as FUNCTIONS with explicit arguments
% (e.g. $\underline{E_g}(\gamma)$); only $\underline{c_c}$ and
% $\underline{O_t}$ are scalars. With \texttt{--no-calib} every underlined
% term is neutralised ($\underline{\cdot} \to 1$, $\underline{O_t} \to 0$);
% the constants $a_1, a_2, t_\ell, t_m$ are part of the model itself and are
% NOT neutralised.

  table fall back to the neutral value $1$ ($\underline{m_g}$ falls back to
