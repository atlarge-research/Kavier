% Kavier training-simulator formulas — verified against

% (branch simplify-kavier-periphery, held-out calibration v3).
%
% Conventions: \textbf{bold} = computed quantity, plain = received input,
% \underline{underline} = calibration term. Calibration terms that depend on
% the configuration are written as FUNCTIONS with explicit arguments
% (e.g. $\underline{E_g}(\text{gpu})$); only $\underline{c_c}$ and
% $\underline{O_t}$ are scalars. With \texttt{--no-calib} every underlined
% term is neutralised ($\underline{\cdot} \to 1$, $\underline{O_t} \to 0$);
% the constants $a_1, a_2, t_l, t_m$ are part of the model itself and are
% NOT neutralised. No Greek symbols are used: configuration arguments are
% spelled \text{model}/\text{method}/\text{gpu}.

  \vspace{2pt}
  {\footnotesize\raggedright $\dagger$~F6 shows the dominant bandwidth term. The
  implemented ring all-reduce over $n$ participants at bandwidth $W$ (in Gb/s,
  applied as $W \times 10^9 / 8$ bytes/s) is
  $A(n, W) = t_l \log_2 n + t_m (n{-}1) + \dfrac{4 \boldsymbol{P_t}}{W}\cdot\dfrac{n-1}{n}$,
  with latency $t_l = 5\times10^{-6}$\,s and per-message overhead
  $t_m = 2\times10^{-6}$\,s. For a single node ($N{=}1$),
  $\boldsymbol{T_c} = [\,G{>}1\,]\,\underline{c_c}\,A(G, W_n)$. For $N{>}1$ it is a
  two-stage reduction, $\boldsymbol{T_c} = \underline{c_c}\bigl(A(\boldsymbol{G_n}, W_n) +
  A(N, W_i)\bigr)$: an intra-node ring over $\boldsymbol{G_n}=\lfloor G/N\rfloor$ GPUs at
  $W_n$ plus an inter-node ring over $N$ nodes at $W_i$. Gradient bytes are
  $4\boldsymbol{P_t}$ (fp32). $\boldsymbol{T_c}=0$ when $G\le 1$.\par}
