Overview

This repository is the home of Kavier, the first scientific instrument for predicting performance, sustainability, and efficiency of LLM ecosystems under inference and training, through discrete-event, cache-aware simulation.

Kavier helps operators, researchers, and engineers predict:

Performance
inference latencies, training throughput, GPU utilization
Sustainability
energy consumption, carbon emissions (kgCO2/Mtoken/s)
Efficiency €
cost per token / sample given GPU-hour prices

The three CLIs at a glance

kavier-perf

Performance

Replay a request trace through a discrete-event, cache-aware simulator to predict latencies, throughput and GPU utilisation.

Read the reference → kavier-energy

Efficiency

Combine Kavier's tasks.parquet with OpenDC's powerSource.parquet into financial and sustainability efficiency metrics.

Read the reference → kavier-train

Training

Simulate a single training config — or every row of a CSV — to estimate tokens/sec and runtime across GPUs and nodes.

Read the reference →

How it fits together

Inputs trace.csv · config

Calibration model × method × gpu
▼              ▼              ▼
Inference engine kavier-perf
Training engine kavier-train
▼              ▼
OpenDC powerSource.parquet
Efficiency kavier-energy

The library feeds both engines; calibration feeds training only. Kavier's outputs flow into OpenDC and back through kavier-energy for the final efficiency summary.

Structure

Kavier is organized into 5 main components:

src/
├── kavier_inference/    # Inference simulation (kavier-perf)
├── kavier_training/     # Training simulation (kavier-train)
├── kavier_energy/       # Efficiency & sustainability metrics (kavier-energy)
├── library/             # Shared GPU & LLM specifications
├── kavier_io/           # Shared I/O utilities
└── tests/               # Test suites

Quick start

git clone https://github.com/<you>/kavier.git
cd kavier

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
python -m pip install -U pip
pip install -e ".[dev]"

Run your first simulation:

kavier-perf --trace src/data/input/input_example.csv

Congrats! You have just run your first simulation with Kavier! See Getting started for the full ten-minute tour.
